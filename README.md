# Retro Dungeon Adventure

A browser-based adventure game inspired by the look and feel of classic Intellivision games. Explore an overworld, enter dungeons, battle monsters, solve puzzles, and collect equipment that opens new paths.

Your goal is to recover two crown halves and sit on the throne in Cloudy Mountain. Characters and objects found along the way provide help, clues, and a few surprises.

## About This Project

This project was a test of using **ChatGPT to aid game development**. ChatGPT assisted with code, debugging, ideas, and development tools. The game was built through repeated experimentation, testing, and refinement.

The game uses JavaScript and HTML5 Canvas, with a deliberately simple retro presentation.
